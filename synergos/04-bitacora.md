# Bitácora

Registro cronológico de cómo evoluciona la idea. Entradas breves: qué se discutió, qué cambió, qué queda pendiente.

## 24 oct 2026. Arranque del cuaderno y primer hilo: la tesis humana

**Contexto.** Alejandro decide que Synergós (antes nombre de trabajo interno) sea su framework propio, con cuatro ejes al mismo nivel: transformación, innovación, IA, y personas y conocimiento. Objetivo doble: interés genuino y posicionamiento profesional de cara a una futura etapa. El documento base tiene el método sólido pero la parte humana no está articulada como tesis: aparece como un habilitador entre cinco.

**Qué se hizo.**
- Se crea el cuaderno en el repo MiLinkedIn (este directorio) para que el pensamiento no dependa de la memoria de un chat.
- Se verifican cuatro referencias base: Trist y Bamforth (1951), Zuboff (1988), Polanyi (1966), Brynjolfsson (2022). Las cuatro existen, dicen lo que creíamos, y quedan fichadas con lo que NO dicen.
- Se formula T1: las personas como criterio de diseño desde el diagnóstico, no como gestión del cambio al final. Con cuatro objeciones escritas.
- Se abren cinco preguntas (P1 a P5). Las que más urgen: P3 (un caso real de Alejandro) y P4 (¿método para consultoras o para la organización que se transforma?), porque cambian el lenguaje de todo lo demás.
- Se deja un backlog de nueve ideas de post.

**Decisiones de Alejandro pendientes.**
- P4: a quién le habla Synergós.
- P3: aportar un caso real, aunque sea anonimizado.
- P5: elegir o escribir la frase de una línea.

**Nivel de investigación acordado:** intermedio. Conocimiento propio más búsquedas web puntuales para verificar o contrastar. Nada de informes largos salvo que un hilo lo merezca.

**Nota de honestidad.** Las tres cifras de mercado (MIT NANDA, Whitelane) vienen del documento base vía resúmenes de prensa. No se han verificado contra fuente primaria todavía. Marcadas así en fuentes.
